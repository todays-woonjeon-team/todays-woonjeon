# 점수 규칙

코드: `core/src/main/java/com/todaysdrive/core/score`, 판정: `core/.../drive/DriveAnalyzer.java`
판정 기준값: `car-app/src/main/assets/rules.properties`(비우면 `RuleConfig` 기본값)

## 1. 오늘의 점수

```
오늘의 점수 = 운세 점수 × 주행 가중치 + 미션 달성 5점
```

| 운세 등급 | 점수 | 비율 |
|---|---|---|
| 대길 | 100 | 20% |
| 길 | 90 | 40% |
| 소길 | 80 | 40% |

- 좋은 운세만 씁니다. 같은 날짜·같은 띠면 차량과 휴대폰에서 같은 운세가 나옵니다(`FortuneTeller`, FNV-1a 해시).
- 운세로 달라지는 폭(80~100)보다 운전으로 달라지는 폭(× 0.5~1.5)을 크게 잡았습니다. 소길이어도 운전을 잘하면 120점, 대길이어도 거칠게 몰면 50점입니다.
- 가중치는 천분율 정수(1000 = 1.0)로 계산해 소수 오차가 없고, 점수는 0.5 이상 올림입니다.

## 2. 주행 가중치(기본 1.0, 최종 0.5~1.5로 제한)

| 항목 | 쓰는 신호 | 판정 | 반영 |
|---|---|---|---|
| 회전 시 방향지시등 | 방향지시등, 핸들 각도, 속도 | 교차로 회전 때 같은 방향 깜빡이가 켜져 있었는지 | 100%: +0.2 / 76% 이상: +0.1 / 50% 이상: 0 / 50% 미만: -0.2 |
| 방향지시등 미리 켜기 | 방향지시등, 핸들 각도 | 깜빡이를 켠 뒤 핸들을 돌리기까지 3초 이상 걸린 비율 | 80% 이상: +0.1 / 50% 이상: +0.05 |
| 부드러운 주행 | 속도, 브레이크, 핸들 각도 | 급가속·급감속·급출발·급회전 횟수를 10km당으로 환산 | 0회: +0.2 / 1회 이하: +0.1 / 2회 이하: 0 / 4회 이하: -0.1 / 초과: -0.3 |
| 빗길 운전 | 와이퍼, 속도 | 와이퍼를 켜고 5km 이상, 그동안 급가속·급감속 없음 | +0.05 |
| 장거리 휴식 | 속도, 기어 | 1시간 30분 넘게 연속 주행한 날, 2시간이 되기 전에 15분 이상 P단 | +0.05 |

- 76%는 전국 평균 점등률(75.7%)을 넘는지를 기준으로 잡은 값입니다.
- 3초 기준: 도로교통법 시행령의 "회전·진로 변경 30m 전(고속도로 100m 전) 신호"를 시속 36km(30m), 시속 120km(100m)로 가는 데 걸리는 시간이 약 3초입니다.
- 회전이 없는 날은 방향지시등 두 항목을 빼고 계산합니다. 차에서 지원하지 않는 신호의 항목도 뺍니다.

## 3. 공정성 규칙

| 규칙 | 값 | 키 |
|---|---|---|
| 점수를 계산하지 않는 거리 | 하루 3km 미만(운세만 보여 줌) | `score.minMeters` |
| 방향지시등 항목 절반 반영 | 하루 10km 미만 | `score.shortTripMeters` |
| 급조작 환산 | 10km당 횟수(오래 달린 사람이 불리하지 않음) | - |
| 티켓 상한 | 점수 티켓 하루 최대 2장 | - |

## 4. 판정 기준값

### 급가속·급감속·급출발

한국교통안전공단이 사업용 차량에 쓰는 위험운전행동 기준을 참고한 초기값입니다. 승용차에 맞게 에뮬레이터 테스트로 조정합니다.

| 판정 | 조건(1초 동안 속도 변화) | 키 |
|---|---|---|
| 급출발 | 5km/h 이하에서 초당 8km/h 이상 가속 | `harsh.start.*` |
| 급가속 | 6km/h 이상에서 초당 6km/h 이상 가속 | `harsh.accel.*` |
| 급감속 | 초당 9km/h 이상 감속(브레이크가 밟혀 있었으면 급브레이크로도 셈) | `harsh.decel.kmhPerSec` |

한 번의 급조작이 여러 신호에 걸쳐 들어와도 한 번만 셉니다. 변화량이 기준의 70% 밑으로 내려가야 다음 급조작을 셉니다(`harsh.releaseRatio`).

### 급회전(급하게 핸들을 꺾음)

25km/h를 넘는 속도에서 4초 안에 진행 방향이 60도 이상 바뀌면 급회전입니다(`harsh.turn.*`). 진행 방향은 핸들 각도와 속도로 추정합니다(자전거 모델: 바퀴 각도 = 핸들 각도 ÷ 조향비 14, 축거 2.7m, `vehicle.*`). 25km/h 이하에서 도는 교차로 회전은 급회전으로 치지 않습니다.

### 교차로 회전

| 조건 | 기본값 | 키 |
|---|---|---|
| 핸들 조작 시작 / 끝 | 20도 이상 / 10도 미만 | `turn.steerStartDeg`, `turn.steerEndDeg` |
| 회전으로 보는 최대 핸들 각도 | 90도 이상 | `turn.minPeakSteerDeg` |
| 추정 진행 방향 변화 | 45도 이상 | `turn.minHeadingDeg` |
| 속도 | 최고 8~40km/h | `turn.minSpeedKmh`, `turn.maxSpeedKmh` |
| 깜빡이 인정 범위 | 핸들 조작 시작 2초 전부터 끝까지 같은 방향 | `signal.graceMillis` |
| 미리 켜기 | 핸들 조작 시작보다 3초 이상 먼저 켬 | `signal.earlyMillis` |

- 후진 중 핸들 조작(주차)과 빠른 속도의 완만한 곡선은 회전이 아닙니다.
- 램프 깜빡임처럼 1.2초 안에 꺼졌다 켜진 신호는 한 번 켠 것으로 이어 붙입니다(`signal.blinkMergeMillis`).
- 비상등은 회전 신호로 치지 않습니다.

### 차로 변경

차로 변경은 핸들 각도 변화가 작아 곡선 주행과 헷갈릴 수 있습니다. 그래서 감점은 판정이 확실한 회전에만 하고, 차로 변경은 **깜빡이를 켠 경우만** 미리 켜기 집계에 넣습니다. 30km/h 이상에서 깜빡이를 1초 이상 켜고 같은 방향으로 핸들을 5도 이상 움직였으면 차로 변경으로 봅니다(`lane.*`).

### 휴식

| 조건 | 기본값 | 키 |
|---|---|---|
| 장거리로 보는 연속 주행 | 1시간 30분 초과 | `rest.longDriveMinutes` |
| 휴식 마감 | 연속 주행 2시간 | `rest.deadlineMinutes` |
| 휴식으로 인정 | P단(또는 시동 꺼짐) 15분 이상 | `rest.minRestMinutes` |

버스·화물차 운전자에게 의무인 "2시간 운전 후 15분 휴식"을 참고했습니다. 거리 대신 연속 주행 시간으로 정한 이유는 막히는 길에서는 짧은 거리도 오래 걸리기 때문입니다.

## 5. 오늘의 행운 미션(+5점)

| 미션 | 달성 조건 | 필요한 신호 |
|---|---|---|
| 오늘 회전은 전부 깜빡이와 함께 | 회전 1번 이상, 모두 깜빡이 | 방향지시등, 핸들 |
| 깜빡이는 핸들 돌리기 3초 전에 | 미리 켜기 80% 이상 | 방향지시등, 핸들 |
| 급브레이크 없는 하루 | 급감속 0번 | 속도 |
| 급출발 없는 하루 | 출발 1번 이상, 급출발 0번 | 속도 |
| 출발 전 전 좌석 안전벨트 | 모든 출발 때 안전벨트 착용 | 안전벨트(선택) |
| 2시간 안에 한 번 쉬어 가기 | 장거리 휴식 가점 조건 | 기어(장거리 예정일만, NaviHelper 연동 후) |

차가 지원하지 않는 신호의 미션은 내지 않습니다(`MissionType.poolFor`).
