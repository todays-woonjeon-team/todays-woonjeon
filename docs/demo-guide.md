# 시연 방법

## 1. PT 시연 순서(출근길 시나리오)

차량 에뮬레이터와 휴대폰(또는 휴대폰 에뮬레이터)을 나란히 둡니다.

| 순서 | 화면 | 보여 줄 것 |
|---|---|---|
| 1 | 휴대폰 | 출근 전 운세 알림 → 오늘의 운세·미션·꿀팁 |
| 2 | 차량 | 시동을 걸면 같은 운세 카드. 띠 운세 설정(생년월일은 차 안에만 저장) |
| 3 | 차량 | 시연 주행 "출근길" 시작 → 주행 중에는 "운전에 집중하세요"만 표시 |
| 4 | 차량 | P단 → 주차 리포트: 점수 계산식, 받은 티켓, 잘한 점·아쉬운 점, 가중치 항목 |
| 5 | 차량 | 룰렛(칸 크기 = 당첨 확률, 확률표 공개) |
| 6 | 차량 → 휴대폰 | 연결 코드 6자리 → 휴대폰에 입력 → 같은 리포트, 주간 기록 |
| 7 | 휴대폰 | 남은 티켓으로 룰렛. 차량에서 다시 열면 티켓이 줄어 있음(한 곳에서 관리) |

vehicle 빌드로 시연할 때는 3번 대신 Virtual Console과 adb로 신호를 넣습니다([차량 신호 연결](vehicle-signals.md) 4절).

## 2. 시연 시나리오

`core/src/main/java/com/todaysdrive/core/drive/DemoScenarios.java`

| 시나리오 | 실제 시간 | 재생 시간 | 판정 | 가중치 |
|---|---|---|---|---|
| 출근길 | 16분 | 약 40초 | 12.4km, 회전 5번 중 4번 깜빡이(미리 1번), 급감속 1번 | 1.2 |
| 서두른 날 | 14분 | 약 40초 | 10.5km, 회전 5번 중 2번 깜빡이, 급가속·급감속 1번씩 | 0.8 |
| 비 오는 퇴근길 | 17분 | 약 40초 | 11.0km, 와이퍼 ON, 급조작 없음, 깜빡이 모두 미리 | 1.5 |
| 고향 가는 길 | 2시간 22분 | 약 40초 | 160km, 1시간 40분 주행 후 20분 휴식, 급감속 9번 | 1.35 |

신호의 시각은 시나리오 시간 그대로라서 판정 결과는 실제로 그만큼 달린 것과 같습니다. 화면에서만 빠르게 재생합니다.

## 3. 시나리오 직접 만들기

`ScenarioBuilder`로 코드에서 만들거나, CSV로 만들 수 있습니다(`ScenarioCsv`).

```csv
time_ms,signal,value
0,GEAR,P
0,SEATBELT,1
2000,GEAR,D
2500,SPEED,2.0
3000,SPEED,4.0
...
60000,TURN_SIGNAL,LEFT
64200,STEERING,-36
64400,STEERING,-72
...
70000,TURN_SIGNAL,NONE
900000,GEAR,P
```

| signal | value |
|---|---|
| SPEED | km/h(1초 간격 권장) |
| STEERING | 핸들 각도(도), 왼쪽 음수 |
| GEAR | P / R / N / D |
| TURN_SIGNAL | NONE / LEFT / RIGHT / HAZARD |
| BRAKE, WIPER, SEATBELT | 1 / 0 |

새 시나리오를 넣으면 `DemoScenariosTest`처럼 기대 결과를 테스트로 먼저 고정해 두고 시연에 씁니다.
